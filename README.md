# cwu-labs-privacy

Privacy policy for the **LISHA - Monitor** iOS app (App Store listing name
"CWU-Labs - Monitor"), served from GitHub Pages at
<https://lisha-cwu.github.io/cwu-labs-privacy/>.

The whole site is the single static file [`index.html`](index.html). There is
no build step: edit the HTML, commit to `main`, and Pages republishes it
within a minute or two.
